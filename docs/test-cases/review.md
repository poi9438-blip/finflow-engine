# RiskWatch 심사 판정 연결 (TC-RISK)

대상: 운영자가 심사를 시작할 때 RiskWatch 판정을 받아 신청에 저장하는 흐름 ([업무 명세 13장](../spec.md#13-riskwatch-심사-판정-5단계))

- **관점:** 정상(판정 저장), 예외(RiskWatch가 응답하지 않거나 거부함, 판정 입력이 없는 예전 신청, 시작할 수 없는 상태), 경계(재시도 횟수), 보안(호출 동안 DB 트랜잭션을 잡지 않음, 서비스 토큰 형식, 비밀키 분리)을 봅니다.
- RiskWatch는 테스트 안에서 띄운 가짜 HTTP 서버로 대신합니다. 실제 토큰 서명·헤더·본문을 그 서버에서 확인합니다.
- 구현보다 먼저 쓰고 구현과 함께 자동화했습니다. 연결 거부는 닫힌 포트로 클라이언트를 직접 불러 확인하고, 나머지는 가짜 RiskWatch가 정해 둔 응답을 돌려줍니다. 응답 시간 초과는 테스트 설정(0.5초)보다 늦게 응답해서 만듭니다.
