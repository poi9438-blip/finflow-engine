# 신청 접수·상태 흐름·감사 기록 (TC-APP)

대상: 신청 접수·조회·취소(서비스), 심사 시작·승인·거절·목록·상세(운영자), 상태 이력 ([업무 명세 3~6장](../spec.md#3-신청))

- **관점:** 정상(접수 → 심사 → 승인/거절, 취소), 예외(잘못된 전이, 진행 중 중복), 경계(입력 범위 양 끝, 거절 사유 500/501자, 목록 size 100/101), 보안(다른 신청자 조회, 소득·DTI 암호화, 목록에 금융 정보 없음)을 봅니다.
- 2단계에서 구현과 함께 자동화합니다. 그때 `작성 예정`을 테스트 위치로 바꿉니다.
