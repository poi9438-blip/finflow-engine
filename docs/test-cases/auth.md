# 인증·인가 (TC-AUTH)

대상: 운영자 로그인, 서비스 토큰·운영자 토큰 확인, 역할 구분 ([업무 명세 2장](../spec.md#2-호출-주체와-인증))

- **관점:** 정상(로그인), 예외(틀린 비밀번호), 경계(시도 제한 5번째·6번째, 토큰 유효 기간 5분), 보안(역할 섞임, 위조·만료 토큰, 삭제된 운영자, 실패 기록의 이메일 원문)을 봅니다.
- 2단계에서 구현과 함께 자동화합니다. 그때 `작성 예정`을 테스트 위치로 바꿉니다.
