# 배치 (TC-BATCH)

대상: 만료 배치(`applicationExpireJob`), 일별 집계 배치(`dailyStatsJob`), 배치 실행·집계 조회 API ([업무 명세 8장](../spec.md#8-배치-4단계))

- **관점:** 정상(만료·집계), 예외(한 건 실패), 경계(만료 기준 시각 앞뒤 1분, 한국 날짜 자정 앞뒤, 조회 기간 92/93일), 보안(서비스 토큰으로 배치 실행 불가)을 봅니다.
- **시각 기준:** 저장은 UTC, "하루"는 한국 날짜입니다. 한국 10월 26일 = UTC 10월 25일 15:00 ~ 10월 26일 15:00.
- 4단계에서 구현과 함께 자동화했습니다. 테스트 데이터는 시각을 정확히 정하려고 SQL로 직접 넣고, 연소득·DTI 칸에는 테스트 키로 만든 진짜 암호문을 넣습니다(만료 배치가 신청을 엔티티로 읽으며 복호화하므로).
