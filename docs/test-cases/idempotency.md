# 멱등성 (TC-IDEM)

대상: 신청 접수의 `Idempotency-Key` 처리 ([업무 명세 7장](../spec.md#7-멱등성-3단계))

- **관점:** 정상(같은 요청 재전송), 예외(같은 키 + 다른 요청, 동시 재전송), 경계(키 길이 7·8·64·65자, 허용 안 되는 문자), 보안(키를 바꿔 다른 사람 신청을 덮어쓸 수 없음 — 다른 키는 새 요청이고, 같은 신청자·상품 진행 중 규칙은 그대로)을 봅니다.
- **같은 요청의 기준:** 본문 문자열이 아니라 검증한 값입니다. JSON 키 순서·공백·숫자 표기가 달라도 값이 같으면 같은 요청입니다.
- 3단계에서 구현과 함께 자동화했습니다. 동시 재전송(TC-IDEM-107)은 두 요청을 진행 중 확인에서 서로 기다리게 해서, 둘 다 키 확인을 통과한 뒤 저장하는 상황을 순서와 관계없이 만듭니다.
